# Heartbeat

Software de monitoreo de salud para astronautas en misiones espaciales — **2026 NASA Space Apps Challenge**.

- **App de escritorio (tripulación, WPF):** registro de signos vitales y check-ups sin conexión, evaluación local y sincronización cuando hay enlace.
- **Portal web (control de misión, Blazor):** revisión de signos vitales por astronauta, alertas críticas y permisos por rol.
- **Backend (.NET 10):** Crew API + Mission Control API sobre una sola base de datos.

> Herramienta de autoevaluación. No es un dispositivo médico ni da diagnósticos.
